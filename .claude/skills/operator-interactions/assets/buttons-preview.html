Button Lab

Ten interaction styles built from motifs already on the site — the status-dot pulse, scatter-text, pixel-image reveal, and terminal-console voice — instead of generic Dribbble hovers. Hover each to see it; all respect prefers-reduced-motion.

01 · magnetic pullGSAP quickTo

Button drifts toward the cursor within a radius, snaps back on leave.

02 · scan lineCSS

A light sweep passes through on hover, like a terminal scan.

03 · status confirmclick state

Click: blue → green, checkmark draws in. Confirms an action landed.

04 · char shufflesetInterval

Hover scrambles the label briefly before it resolves — echoes ScatterText.

05 · diagonal fillclip-path

Fill sweeps in from the bottom-left corner instead of a flat wipe.

06 · bracket expandCSS

Terminal brackets spring open on hover, console-native feel.

07 · progress drainSVG stroke

Border draws like a loading bar, blue → green — "agent is working."

08 · pixel dissolveCanvas

Label pixelates out and back in as a new one — same technique as project card reveals.

09 · split flap3D flip

Departure-board flip reveals a second, more specific label.

10 · signal pingCSS radar

Radar ping from the status dot — same motif as the hero's "online" badge.
