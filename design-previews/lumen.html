Frequently Asked Questions

What exactly is a Digital FTE?

A Digital FTE (Full-Time Equivalent) is a background AI agent set up to perform a sequence of repetitive tasks. It handles operations independently (such as email processing, scheduling, and logging data) rather than waiting for manual inputs like a regular chatbot.

Do you offer post-handover support?

Yes. Every deployment includes an optional SLA for routine monitoring, token cost optimization, API key rotations, and adjustments if your business SOPs change.

Which LLMs do the agents run on?

We configure agents to use the model that best fits the budget and complexity. Usually, this means OpenAI GPT-4o, Anthropic Claude 3.5 Sonnet, or fine-tuned open-weight models (Llama 3) for self-hosted instances.
